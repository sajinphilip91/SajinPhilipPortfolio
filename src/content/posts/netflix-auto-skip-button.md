Hey Netflix, I was watching 1899(A Netflix series) continuously for 3 to 4 episodes. I enjoy seeing the introduction for the first time, and possibly the second as well. But, I find it a little unpleasant to see the introduction for each episode before it started. Indeed, there is a button to "Skip" the introduction. Yet as a user, I must constantly click.

Can we customise it for each user by offering a skip intro option for upcoming episodes? And from the same screen, the user should be able to access it again when necessary.
